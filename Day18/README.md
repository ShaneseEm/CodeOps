# Day 18 - Arrays, Objects & Modern JavaScript

## Exercises

### Exercise 1
Used `map()` to add 15% VAT, `filter()` to keep prices under 1000 ETB,
and `reduce()` to calculate the grand total.

### Exercise 2
Created a customer object and used `Object.entries()` with a `for...of`
loop to display every key and value.

### Exercise 3
Used object destructuring to extract `name` and `city`. Also used
parameter destructuring in the `greet()` function.

### Exercise 4
Used the spread operator to create an updated customer object without
mutating the original object.

### Exercise 5
Created a small JavaScript module system.

- `money.js` contains the VAT constant and `addVat()` function.
- `app.js` imports and uses them.

## Concepts Practiced

- map()
- filter()
- reduce()
- Object.entries()
- Object destructuring
- Parameter destructuring
- Spread operator
- ES modules
- Named exports and imports
